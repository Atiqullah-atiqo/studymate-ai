# StudyMate AI 🎓

## Live Demo

🌐 **Live App:** https://studymate-ai-tau.vercel.app/

## About The Project

StudyMate AI is an AI-powered assignment helper designed to help students understand difficult topics, solve academic questions, and learn concepts with simple step-by-step explanations.

Many students struggle when assignments contain complex questions or unfamiliar topics. StudyMate AI provides instant explanations, examples, and learning guidance using artificial intelligence.

## Problem It Solves

Students often waste time searching multiple websites to understand assignment questions. StudyMate AI provides a simple AI tutor experience where students can:

* Ask academic questions
* Receive clear explanations
* Understand concepts step by step
* Learn with examples

## How To Run Locally

Clone the repository:

```bash
git clone https://github.com/Atiqullah-atiqo/studymate-ai.git
```

Go into the project:

```bash
cd studymate-ai
```

Install dependencies:

```bash
npm install
```

Create a `.env.local` file:

```
GROQ_API_KEY=your_api_key_here
```

Start the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
